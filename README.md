# Tiny Games

Nine simple one-button games for little kids. Open `index.html` in any browser, or play it online.

Dino Run, Fly Bird, Stack Tower, Hop Frog, Shop & Drop, Go Fishing, Snack Time, Space Dash and Colour Catch.

Controls: SPACE (or tap) in every game. Esc = back to the menu, M = sound, H = hints.
